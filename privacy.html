Pin Pilot Privacy Policy

Last updated: 1 November 2026

Pin Pilot is a personal tool used by Ahmed Rabea to publish his own design portfolio images to his own Pinterest account. It is not offered to the public and has no other users.

What data it uses

Pin Pilot uses the Pinterest API to read the owner's Pinterest boards and account name, create boards, and create Pins on the owner's own account. The Pins contain images, titles, descriptions and links that the owner wrote and designed.

What data it stores

The Pinterest access tokens and the app credentials are stored only on the owner's personal computer. Pin Pilot does not run a server, does not collect data about other Pinterest users, and does not share, sell or transfer any data to third parties.

Removing access

Access can be revoked at any time from Pinterest settings under Security and logins, Apps. Deleting the tool's local folder removes all stored data.
